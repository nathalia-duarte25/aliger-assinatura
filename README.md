# Assinatura de e-mail da Aliger

Hospeda as imagens da assinatura de e-mail da Aliger e a página que gera a assinatura pronta para colar no Gmail.

- Gerador: https://nathalia-duarte25.github.io/aliger-assinatura/
- Imagens: `img/` (servidas pelo GitHub Pages em `/aliger-assinatura/img/...`)

**Não renomear nem apagar arquivos de `img/`.** As assinaturas já instaladas no Gmail apontam para esses endereços; mudar um nome quebra a imagem em todos os e-mails.

Ícones: [Phosphor Icons](https://phosphoricons.com) (MIT).
